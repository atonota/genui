The normative private Temporal packet binds the original document SHA and the current human-decision SHA. Source authors own disjoint files and never run checks or edit decisions. Root admits serially after genuine RED. Every required criterion must have concrete evidence before completion.

## Current status — maintenance 2026-10-17

The FAB is an implemented local candidate: actual source under `src/fab/`, a public `GenUXFab` export and the 41st docs slug. The GenUX runtime count of 61 is separate and unchanged. A candidate is not acceptance: this record accepts none of the 63 criteria below, and Temporal authoring success, source integration, criterion acceptance, main, CI, Pages and live are distinct states. Root records per-row source and actual behavior evidence as pass/fail/not_run/not_applicable; FAIL or not_run never becomes PASS or DONE. Defaults use the central Cubic motion and central scrim roles; alternate FAB easing and backdrop values still await the pending human exception, and the renderer rejects unsupported alternatives instead of silently aliasing them. Maintenance rules live in `AGENTS.md`.

## Verification boundary

Only necessary FAB behavior tests and existing mandatory project gates. No historical catalog test wave, source-only completion claim or fabricated live service. Real hardware and actual Safari remain separate from browser emulation. Human visual approval is distinct from independent source/UI review.

## Frozen cross-package API contract

Relative imports in types.ts must resolve GenUXIcon as `../react/GenUXIcon`. Root owns shared route/registry/package integration. These declarations predate the implementation (historical wording); the local `GenUXFab` candidate now implements them, while criterion acceptance, main and live stay separate. `FabGroup.layout` names one dial arm of a multi-directional FAB, so it excludes `multi-directional`, `floating-menu` and `sheet`; all nine top-level layouts stay supported, and a group carrying one of those three is rejected at runtime instead of being aliased to linear.
